## How to Use This Package

Give Claude Design the complete contents of `03-Claude-Design-Prompt-EN.md`, and attach the architecture and implementation plan as functional context. The prompt instructs Claude Design to ask about genuinely unresolved decisions without reopening requirements that have already been agreed.

For application implementation, use the architecture and implementation plan alongside the actual design handoff generated by Claude Design.

## Language Changes in This Edition

All document prose, tables, diagram labels, code comments, examples, and filenames are English. Default UI copy and sample book titles are English. The earlier requirement for a non-English primary prototype and mandatory bilingual deliverables has been removed. Strings remain externalized to support optional future localization.

The agreed architecture, functionality, technical caveats, and numbered source references are preserved.

## Status and Caveats
