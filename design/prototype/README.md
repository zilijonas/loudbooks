Open **../Prototype.dc.html**. Left panel: four scenarios with steps, live state, simulation tools (+5 min, end session, interrupt, error, require tap, airplane, near book end, disconnect), viewport (320/390/430/1440/both), theme and reduced motion.

1. Empty → Add → files → reorder → Save → details → prepare 30 min → Play → 1.5× rebuild → Pause → session end → Resume with 5 s rewind.
2. Chapter timer → stop at boundary → Resume at next chapter.
3. Computer Send ↔ phone Receive (code 482915) → book in library → offline player; disconnect recovery.
4. Edit, delete, clear temporary files, dark theme, playback error, storage-full import, delete library.
